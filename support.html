常见问题

需要注册账号吗？

不需要。打开就能记账，所有数据默认只保存在你的设备上。

数据会不会丢？怎么备份？

账目保存在设备本地，会随 iPhone 的整机备份（iCloud 备份或电脑备份）一起备份。如果你希望有一份独立、可读的备份，可以在「设置 → 数据同步」里配置你自己的 Git 仓库（Gitea 或 GitHub），账本会按月导出成 JSON 文件写入你的仓库。这项功能完全可选，且数据存在你自己的仓库里，不经过开发者的任何服务器。

换手机了，怎么把账本带过去？

最简单的方式是用 iPhone 的整机迁移或从备份恢复。如果你配置过 Git 同步，也可以在新设备上填入同一个仓库和令牌，账本会自动拉取合并（合并策略为「更新时间较新者优先」，并支持删除标记）。

AI 记账要额外付费吗？

App 本身免费、无内购。AI 识别功能需要你填入自己申请的 API Key（支持 DeepSeek、OpenAI、Gemini），费用由你和相应服务商结算，开发者不参与也不代理请求。不配置 AI 也完全不影响记账、统计和资产功能。

为什么要定位权限？

仅用于在账本页顶部通过 Apple 天气显示当地天气，请求的是「使用 App 期间」的粗略位置。拒绝该权限不影响任何记账功能，只是不显示天气。

「本地网络」权限是干什么的？

如果你的 Gitea 服务器架在家里的局域网内（比如 NAS 上），App 需要该权限才能连上它。不使用局域网同步的话可以拒绝。

「我的东西」里的每日成本是怎么算的？

用购入价格除以从购买日至今（或至结束日）的持有天数。东西用得越久，每天摊到的钱越少。

怎么用截图记账？

App 提供了「获取记账分类」和「批量记账」两个快捷指令操作。你可以在系统「快捷指令」App 里搭一条流程：截屏 → 文字识别 → 交给模型解析 → 批量入账。项目仓库中的《快捷指令-截图记账.md》有完整配方。

可以删掉所有数据吗？

可以。在「设置」里有清空本地数据的选项。如果你配置过 Git 同步，远端仓库中的历史提交需要你自行在仓库服务中删除。

Frequently asked questions

Do I need an account?

No. The app works immediately after install, and by default all data stays on your device.

How do I back up my data?

Records live in local device storage and are included in your iPhone's full device backup (iCloud or computer). For an independent, human-readable backup, you can configure your own Git repository (Gitea or GitHub) under Settings → Sync; the ledger is exported as monthly JSON files into your own repository. This feature is optional, and the data never passes through any server operated by the developer.

How do I move my ledger to a new phone?

The simplest route is iPhone-to-iPhone transfer or restoring from a backup. If you use Git sync, entering the same repository and token on the new device will pull and merge your ledger (last-updated-wins, with tombstones for deletions).

Does AI entry cost extra?

The app itself is free with no in-app purchases. AI parsing requires your own API key (DeepSeek, OpenAI, or Gemini); billing is between you and that provider. The developer neither proxies the request nor receives your key. Everything else in the app works without it.

Why does the app ask for location?

Only to show local weather at the top of the ledger via Apple Weather, using coarse, while-in-use location. Denying it does not affect any bookkeeping feature.

What is the Local Network permission for?

It is needed only if your Gitea server runs on your home network (for example on a NAS). Decline it if you do not use LAN sync.

How is the daily cost in "My Things" calculated?

Purchase price divided by the number of days you have owned the item (through today, or through its end date). The longer you keep something, the lower its daily cost.

Can I delete everything?

Yes — Settings includes an option to erase all local data. If you configured Git sync, commit history in your remote repository must be removed through that service.
